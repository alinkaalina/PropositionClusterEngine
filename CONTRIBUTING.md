# Contributing to PropositionClusterEngine

Contributions to improve test coverage, documentation, and clustering invariants are welcome!

## Workflow

1. Fork the repository and create a feature branch (`git checkout -b feature/improvement`).
2. Add or update unit tests in `test_cluster_engine.py`.
3. Run the test suite locally (`pytest test_cluster_engine.py -v`).
4. Submit a Pull Request against `main`.
